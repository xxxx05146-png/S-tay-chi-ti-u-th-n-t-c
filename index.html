📄 Hướng dẫn mã Google Apps Script mẫu
  1. Mở file Google Sheet của bạn > Chọn Tiện ích mở rộng > Apps Script.
  2. Dán đoạn mã script dưới đây và nhấn Triển khai > Triển khai mới:
function doPost(e) { var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet(); var data = JSON.parse(e.postData.contents); sheet.appendRow([ new Date(), data.formattedDate, data.type, data.category, data.amount, data.balanceAfter ]); return ContentService.createTextOutput(JSON.stringify({status: "success"})) .setMimeType(ContentService.MimeType.JSON); }

Chọn quyền truy cập: Bất kỳ ai (Anyone) rồi copy URL dán vào ô trên.
